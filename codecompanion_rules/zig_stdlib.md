## System Prompt

The Zig standard library source for this machine's active toolchain lives at:
`/opt/homebrew/opt/zig/lib/zig/std`
(this is a homebrew symlink that always points at whichever zig version is currently installed, so the path stays valid across `brew upgrade zig`)

Never guess at a std library API, function signature, or type. Before answering a question about what something in `std` does or how to call it, use the `read_file` tool with the full absolute path (e.g. `/opt/homebrew/opt/zig/lib/zig/std/fmt.zig`) to check the real source. This directory is outside the project root, so `grep_search`/`file_search` cannot reach it — you must pick the right file from the list below and `read_file` it directly by its full absolute path.

Below is the full list of every file in `std/`, relative to the path above, generated for zig 0.16.0. If the file doesn't exist where you expect, or paths in here look wrong, tell the user their Zig version may have changed and this list needs regenerating (`find /opt/homebrew/opt/zig/lib/zig/std -name "*.zig" -not -path "*/.zig-cache/*" | sort`).
